# Instagram profile setup

**Username:** `i80.things`

## Recommended name

> **I-80 Things | Nebraska News**

27 characters. "I-80" and "Nebraska" are the searchable terms people actually use; "Things" keeps the brand.

## Recommended bio

> Daily I-80 Nebraska news. Crashes, closures, weather & road conditions from Omaha to Kimball. Full stories + sources ↓

118 characters (Instagram allows 150). It names the corridor, the coverage, and the towns at both ends, then tells people where the link is.

## Highlights

Create five, in this order:

1. **Crashes** — confirmed incidents only
2. **Weather** — winter storms, closures, warnings
3. **Construction** — NDOT projects and lane closures
4. **Road conditions** — 511 explainers, plow days, service gaps
5. **Towns** — Omaha, Lincoln, Kearney, North Platte, Sidney, Kimball

## First caption format

```
Before you drive I-80 today.

<Headline>

<One line of context: what happened, where, status.>

📍 Kearney, Nebraska (I-80 mile 272)

Full story → link in bio.

#Nebraska #I80 #Kearney #NebraskaWeather
```

Rules:

- Catchy hook first; keywords matter more than hashtags.
- No URL in the caption. Instagram does not make it clickable.
- Put the story URL in the bio before posting; the admin **Instagram kit** has a **Copy bio link** button.
- 3–5 precise hashtags, not a wall.
- Use one to ten real photos. A carousel works well with 2–5; put the strongest image first.
- Each selected image gets its own 1080×1350 JPEG, with the brand icon in the corner as a watermark.
- Credit the photographer in each image (the generated JPEG includes the credit line).
- Choose the Instagram images in the admin **Instagram kit** with the carousel checkboxes; the manual post and the API carousel use the same selected set.
